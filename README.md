# Younes Magdy - Portfolio Website

## How to upload to GitHub Pages

### Step 1: Download the images
You need to download these 4 images from your device and add them to this folder:
- D70A837D-B60B-4F4C-AF8D-4753DB5E40DE.jpg
- 48C61904-C1A2-4417-AA82-2E5B1C14A429.jpg
- 5BD885FD-B07A-4F37-8ABC-C84704B91DA0.jpg
- 4BDADC02-ADC1-46E0-8D20-7B2F1ECCE326.jpg

### Step 2: Upload to GitHub
1. Go to your repository: https://github.com/yourusername/younes-magdy-portfolio
2. Click "Add file" → "Upload files"
3. Drag and drop ALL files (index.html + 4 images)
4. Click "Commit changes"

### Step 3: Enable GitHub Pages
1. Go to Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Click Save

### Step 4: Wait 2-5 minutes
Your site will be live at:
https://yourusername.github.io/younes-magdy-portfolio
